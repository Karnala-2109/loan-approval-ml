How the Prediction Works

1. The user enters loan applicant information.

2. The frontend sends the information to the FastAPI backend.

3. The trained Logistic Regression model processes the input.

4. The model predicts whether the loan is approved or rejected.

5. The application displays the prediction and approval probability.
